NewAnalysisView.swift 修正箇所

【1】importを変更

現在:
import SwiftUI
import PhotosUI
import SwiftData

変更後:
import SwiftUI
import SwiftData


【2】selectedItem を変更

現在:
@State private var selectedItem: PhotosPickerItem?

変更後:
@State private var showVideoPicker = false


【3】動画選択ボタンを変更

現在のこの部分:

PhotosPicker(
    selection: $selectedItem,
    matching: .videos
) {
    Label(
        "スロー動画を選択",
        systemImage: "video"
    )
}

を全部削除して、次に置き換える:

Button {
    showVideoPicker = true
} label: {
    Label(
        "スロー動画を選択",
        systemImage: "video"
    )
}


【4】一番下の .onChange(of: selectedItem) { ... } を丸ごと変更

NewAnalysisView の末尾付近にある:

.onChange(of: selectedItem) { _, newItem in
    ...
}

を、開始の .onChange から閉じカッコまで丸ごと削除し、
次に置き換える:

.sheet(isPresented: $showVideoPicker) {
    VideoPickerView(
        onPicked: { url, filename in
            showVideoPicker = false

            Task {
                if let saved = VideoCalibrationStore.load(
                    videoName: filename,
                    context: modelContext
                ) {
                    calibration = saved
                }

                await vm.analyze(
                    url: url,
                    videoName: filename,
                    captureFPS: captureFPS,
                    distanceM: distanceM
                )

                recalcUncertainty()
            }
        },
        onCancel: {
            showVideoPicker = false
            vm.status = "動画選択をキャンセルしました"
        }
    )
}


注意
====
private func recalcUncertainty() は削除しないでください。

正しい並びは概ね:

}
.navigationTitle("新規解析")
.sheet(isPresented: $showVideoPicker) {
    ...
}

private func recalcUncertainty() {
    ...
}

となります。
